保持專注，看見時間的去向。

Promoscope 是一款內建於瀏覽器的番茄鐘計時器，能在每個工作時段自動追蹤你瀏覽了哪些網站。計時結束後，你會看到一份清晰的時間分佈圖表，完全不需要手動紀錄。

使用方式

1. 從擴充功能彈出視窗啟動一個番茄鐘
2. 照常工作 — Promoscope 會在背景安靜地追蹤你的活動分頁
3. 時段結束時，查看圖表了解你的時間如何分配在各個網站上

功能特色

● 番茄鐘計時器，含工作、休息、長休息循環
● 自動依網域追蹤網站使用時間 — 免設定、免手動輸入
● 每次時段結束後以圓餅圖呈現時間分佈
● 每日統計：已完成輪數與總工作時間一目瞭然
● 擴充功能圖示上顯示倒數計時，隨時掌握剩餘時間
● 時段結束時發送通知提醒
● 可自訂工作、休息、長休息的時間長度
● 支援繁體中文與英文

為什麼要安裝 Promoscope？

大多數番茄鐘應用只提供計時功能。Promoscope 更進一步 — 它回答了一個關鍵問題：「我的時間到底花在哪裡？」不需要任何額外操作，每次工作時段結束後，你都能誠實地看到自己的專注狀況。

無論你是開發者、學生、寫作者，還是遠端工作者，Promoscope 幫助你對自己負責 — 不是透過罪惡感，而是透過覺察。

隱私優先

所有資料都儲存在你的裝置上，不會傳送到任何伺服器。無需帳號、無需註冊、不會追蹤你瀏覽器以外的任何資訊。
